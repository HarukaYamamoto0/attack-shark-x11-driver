# Vibration Mode Change Notification

> To better understand this document, first read the `README.md` file located in the root of this directory.
>
> This document remains incomplete due to limited information about this functionality. I currently do not own a mouse
> equipped with a vibration motor, so I have been unable to verify the behavior experimentally.

This event is only generated by mouse models equipped with a built-in vibration motor.

Whenever the user changes the vibration mode using the dedicated hardware button, the firmware sends this event to
notify the host of the newly selected mode.

The only model I am currently aware of that implements this event is the `INPHIC IN9 Ultra`. Since I do not own this
model, the information provided in this document may be incomplete or inaccurate.

## Structure

| Event Code | Param 1 | Param 2        |
|------------|---------|----------------|
| `0x11`     | `0x00`  | Vibration Mode |

### Event Code

Identifies a vibration mode change notification.

This event is automatically generated whenever the user cycles through the available vibration modes using the dedicated
hardware button.

### Param 1

The purpose of this parameter is currently unknown.

All known firmware references to appear to treat this parameter as unused, and no observed behavior suggests that its
value
affects how the event is processed.

### Param 2

Indicates the newly selected vibration mode.

The known values are:

|  Value | Description        |
|-------:|--------------------|
| `0x00` | Vibration Disabled |
| `0x01` | Standard           |
| `0x02` | Enhanced           |
| `0x03` | Explosive          |

These mode names are taken from the official software localization files.

## Example

```text
03 55 11 00 00
│  │  │  │  └── Vibration Mode: Disabled
│  │  │  └───── Fixed
│  │  └──────── Event Code: 0x11
│  └─────────── Device ID
└────────────── Report ID
```

## Notes

As previously mentioned, this document contains limited verified information and should be treated as a preliminary
reference rather than a definitive specification.

The vibration system of the `INPHIC IN9 Ultra` requires further investigation, as the available evidence suggests that
its implementation may involve bitwise masking operations.
